## Interpretation

- `semantic_keyword` is the existing deterministic action-policy baseline on the same chosen/rejected pairs.
- `learned_perceptron` is trained and evaluated on all reranker pairs, so it only proves the current data is linearly separable.
- `learned_perceptron_loto` trains on all but one task and evaluates the held-out task, giving the first offline generalization check before changing runtime prompts.
- `learned_perceptron_loso` trains on all but one suite and evaluates the held-out suite, making supervised-data transfer failures visible before runtime integration.
